# ۲۰۴۸

بازی کلاسیک ۲۰۴۸ در قالب **یک فایل HTML** — بدون هیچ وابستگی، فونت یا کتابخانه خارجی.

## اجرا

فایل `index.html` را در مرورگر باز کنید. همین. (یا `python3 -m http.server` و رفتن به `http://localhost:8000`)

## امکانات

- حرکت با کلیدهای جهت‌دار یا `W A S D`، و کشیدن انگشت (سوایپ) روی موبایل
- انیمیشن نرم جابه‌جایی و ترکیب خانه‌ها
- امتیاز، رکورد و ذخیره خودکار بازی در `localStorage`
- دکمه بازگشت (Undo) تا ۳۰ قدم
- صفحه برد و ادامه بازی پس از رسیدن به ۲۰۴۸، تشخیص پایان بازی
- اعداد فارسی/انگلیسی (دکمه ۱۲۳) و رابط راست‌به‌چپ
- طراحی واکنش‌گرا برای موبایل و دسکتاپ، پشتیبانی از `prefers-reduced-motion`
